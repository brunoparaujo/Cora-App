# Cora Engine

Motor de planejamento do app Cora.

- `engine-browser.js`: empacota os motores congelados usados no navegador.
- `integration-core.js`: adapta o plano gerado ao modelo operacional do app.
- `integration-ui.js`: conecta onboarding, clima, orçamento, Firebase e interface.
- `data/`: catálogo, preços, regras e configurações consumidos pelo motor.

O nome da pasta é funcional e não depende da versão do app. As revisões internas continuam registradas nos próprios dados e módulos.
